# 🇮🇳 Independence Day Animation Projects

Celebrate the spirit of **India's Independence Day** with programming! 🇮🇳

This repository contains **two different implementations** of an animated Indian Tricolor celebration:

1. 🐍 **Python + Tkinter**
2. 🌐 **HTML + CSS + JavaScript Canvas**

Both versions create the Indian Tricolor with animation, an Ashoka Chakra, fireworks, and a patriotic Independence Day message — using two different programming approaches.

---

## ✨ Demo

The project includes animated implementations created using Python and Web technologies.

---

# 🐍 Method 1 — Python + Tkinter

The Python version uses Python's built-in **Tkinter** graphics library to create the animation.

### 📖 Description

This program creates an animated Independence Day scene completely using Python.

It uses:

- Python
- Tkinter Canvas
- `math`
- `random`

The animation includes a rising flag pole, waving Indian Tricolor, Ashoka Chakra, fireworks, and a patriotic message.

### ✨ Features

✅ Animated **waving Tricolor flag**  
✅ **Ashoka Chakra** with 24 spokes  
✅ Rising **flag pole and podium**  
✅ Animated **fireworks effects**  
✅ Tricolor **Happy Independence Day** message  
✅ Uses mathematical functions for the waving effect  
✅ No external Python libraries required

### 🛠 Requirements

- Python 3.x
- Tkinter

Tkinter is normally included with standard Python installations.

### 🚀 How to Run

Run the Python file:

```bash
python independence_day.py
