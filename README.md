# 🇮🇳 Independence Day Python Project  

Celebrate the spirit of **India’s Independence Day** with this Python program!  
This project draws the **Indian Flag** using Python’s `tinkter` graphics module and adds animated fireworks with a festive “Happy Independence Day” message.

## 📖 Description  

This project is a fun and creative way to showcase programming skills while celebrating India’s Independence Day 🇮🇳.  
It uses the `tinkter` module in Python to:  
- Draw the **Indian tricolor flag** with the Ashoka Chakra.  
- Display animated **fireworks** around the flag.  
- Show a **Happy Independence Day** greeting in the national colors.  

Perfect for beginners learning graphics in Python or for a festive programming activity! 🎉  

---

## ⚡ Features  

✅ Animated **waving tricolor flag**  
✅ **Ashoka Chakra** in the center  
✅ **Fireworks effects** for celebration  
✅ **Text banner** saying “Happy Independence Day”  

---

## 🛠 Requirements  

Make sure you have the following installed:  

- **Python 3.x** (recommended: Python 3.8 or later)  
- No external libraries are needed — only Python’s built-in `tinkter` module
